# P2: "O Brasil votando", a 60-second replay of election day

Goal: an animated map of Brazil, 08:00 to 18:30 Brasilia, every town lit by its votes per
minute, as a web page and a short video, built from the round 2 lake. No claim about the
result; the page shows when the country voted. Then "Minha seção": a shareable card per section.

Why this and not more verification: the TSE releases the logs; media and a dozen GitHub
projects already count votes after 17:00, log vs BU, manual admissions and 100% sections.
Nobody shows the timestamps. A visual with no claim can be shared by both sides.

Facts this plan builds on (checked 2026-10-28):
- Round 2 lake: 497,896 sections with a log, 127.7M `voto_computado` rows with urna time;
  `main.fuso_municipio` gives each town's offset from Brasilia.
- A replaced urna's log is nested as a second `.jez` inside `-log.jez` (DataUrnas-BR,
  `docs/investigacao-log-bu-2026.md`). `logparse.extract_logd` reads only the outer `logd.dat`,
  so 1,429 sections with `contingencia` fail the turnout check.
- Prototype of `secao_dia` on round 2: 8.5 MB; power cuts, opening and closing times and manual
  admission share all come from untyped lines (`Urna operando na bateria interna`, `Urna pronta
  para receber votos`, `Operador selecionou: Encerrar votação`, `Solicita digital. Tentativa`).
- Storm in MG on 25 Oct: CNN reports 160+ voting places without power; the lake shows 3,031
  sections in Belo Horizonte on battery while voting. The replay should show it.

Decisions (2026-10-28): page on GitHub Pages from this repo; name "O Brasil votando"; T1 and
T2 built in the operator session, PR by PR.

## Tasks (in order; T3 needs a look from Robson before T4)

### T1 parser: nested `.jez`
- `extract_logd` returns every `logd.dat` found: the outer one and any inside a nested `.jez`.
- Rows keep `id_urna`; `arquivo_hash` stays the outer file's hash; add `urna_ordem` (0 = replaced,
  1 = closing) or equivalent so a section's two urnas can be told apart.
- Reparse from `raw/` (no network). Done when `check_comparecimento` shows 0 `contingencia`
  mismatches on round 2.

### T2 tables
- `sql/views/votos_minuto.sql`: (ano, turno, sigla_uf, id_municipio_tse, minuto_bsb, votos).
- `sql/views/secao_dia.sql`: one row per section and round: abertura, encerramento,
  primeiro_voto, ultimo_voto, votos, habilitados, biometricos, tentativas_digital, quedas,
  min_bateria, modelo, contingencia. Needs about 15 new `EVENT_TYPES` patterns.
- Export both as Parquet for the site (`votos_minuto` binned to keep the page under 4 MB).

### T3 static frame
- IBGE town centroids (or TSE `municipio` plus a centroid file) joined by `id_municipio`.
- One canvas frame at 13:30: dots sized by electorate, lit by votes in that minute. Robson
  approves the look.

### T4 replay page
- Canvas, 630 frames, 60 s loop, scrubber, clock, running total, three callouts (lunch dip,
  MG storm 13:30, 17:00 close). Works on a phone. Static site in `docs/site/`.

### T5 video
- Playwright renders frames; ffmpeg makes 9:16 and 16:9 MP4 with burned subtitles, under 20 MB.

### T6 copy
- pt-BR page text, 4-line method note, credit "Dados: TSE, logs das urnas", link to repo and data.

### T7 publish
- GitHub Pages from this repo; Hugging Face dataset with `secao_dia`, `votos_minuto`, typed
  `eventos`; posts are Robson's.

### T8 "Minha seção" (after T7)
- Lookup by town and section; card with open, close, first and last vote, fastest voter, power
  cut, rank against the country; share image.

### T9 round 1 collection (background, after T4)
- `collect-logs --turno 1`, all states, about 8 to 9 h.

## Not in scope
- Any statement about candidates, fraud or the result. Vote choice is not in the log.
