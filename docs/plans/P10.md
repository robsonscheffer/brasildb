# P10: extras that need an account or are less certain

Goal: add the sources that need a key or account, or where availability is not yet proven.
Each item ships on its own once its access is in place.

## Items

- E1 Emendas with author. Links a deputy's money to each receiving municipality, to compare
  with that deputy's votes there. Source: the Portal bulk file, no key
  (`download-de-dados/emendas-parlamentares/UNICO`, 32.5 MB zip, checked 2026-11-01), three
  CSVs, `;`, latin-1:
  - `EmendasParlamentares.csv`: 94,769 rows, 2014 to 2026, author code and name, `Código
    Município IBGE` (7 digits on 37,709 rows; the rest "Sem informação" for several cities,
    national or a state), function, program, action, committed, settled and paid values.
  - `EmendasParlamentares_PorFavorecido.csv`: 828,563 rows, 2014-06 to 2026-10, per recipient
    (company, person, agency) with UF and city name, no city code.
  - `EmendasParlamentares_Convenios.csv`: 85,403 rows, emenda to federal agreement.
  The API `/emendas` has the same fields but no city filter, 15 rows per page and the city as
  text, so it is not the loader.
  Open, for the plan owner: which measure is "money a deputy sent to a city". For Blumenau the
  two files differ widely (2026: R$ 500,000 paid by IBGE code in the first file, R$ 23,680,008
  received by recipients in the city in the second).
- E2 Night lights: NASA VNP46A4 yearly composite, about 460 m pixels; sum in 1 km around each
  voting place as an income proxy below the municipality. Needs a NASA Earthdata account
  (research note a11; no values yet).
- E3 Economy by sector: IBGE GDP value added by sector (SIDRA 5938; 2021 shares, the 2023
  shares show "..."), BCB SICOR rural credit per municipality (research note a10).
- E4 CadÚnico family counts by income band and Censo SUAS (CRAS, CREAS): MDS tools redirected
  during research; find a working source first.
